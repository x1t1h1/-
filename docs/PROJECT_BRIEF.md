# 项目简报 · 热知

本文件为团队协作公开版说明，不包含原始申报材料及团队个人信息。

## 项目目标与现状

面向工程热力学自主学习，将知识图谱、教学资源、练习反馈与学习记录连接起来。当前交付为 Uni-app + Vue 3 + TypeScript 的 H5 前端，使用 Vite 构建、ECharts 绘制图谱、KaTeX 显示公式。

已实现：首页、知识图谱、仿真实验、视频与课件、习题练习、个人中心。知识图谱支持关联图谱（默认）、章节学习路径和先修顺序三种可切换视图，用于呈现知识联系和零基础学习顺序。仿真实验以实验卡片列表进入独立详情页，当前内置卡诺循环和 4 个理想气体基本过程示例模型；模型在浏览器内计算，并提供统一的组员模型接入契约，新增模型会自动生成卡片与详情页。包含 13 章、32 个精选知识点、42 条关系、90 项资源、16 道自编单选题。资源包括 3 个自制无声视频、3 组文字课件、13 份课程 PDF 与 71 个外部网课分集。

判分在前端进行；学习记录保存在当前浏览器 localStorage，不跨设备同步。已学知识点根据完成资源关联推算，不代表掌握程度。外部网课仅提供公开页面链接，需要联网；实际教学内容与播放仍需人工复核。

AI 助教已在 HTML 入口配置交晓智官方 WebSDK 聊天气泡，采用智能体提供者从平台嵌入设置取得的初始化代码。智能体和知识库继续由交晓智管理，热知不自动发送学习记录、错题或仿真参数，也不保存后端 API 密钥。本次以校园网、本校师生及学校账号访问权限为运行前提；SDK 加载异常时提供重试提示，原有学习功能继续使用。真实登录、权限、文字问答、连续追问与移动端布局均待校园网人工联调确认，不能将入口配置视为问答验收完成。操作与竞赛运行环境说明见 README 的“AI 助教”章节。

## 后续规划（尚未实现）

当前已提供前端示例仿真模型与统一接入契约；后续计划补充更多参数可调仿真、进行小范围试用，再建设 Python + FastAPI 后端、MySQL 用户与学习记录存储，以及自建的课程 RAG 答疑与个性化推荐。交晓智 WebSDK 入口不代表这些独立后端能力已经实现。

服务器、接口地址、用户鉴权与 CORS 方案需团队确认后实施。当前不创建空壳后端，不把未来能力表述为已完成。AI 回答准确率 ≥85% 属于目标，需要测试结果证明。

## 内容维护与边界

章节以 `docs/COURSE_OUTLINE.md` 为准；资源关联以 `docs/RESOURCE_MAPPING.md` 为依据，分集快照只用于检查。`src/data/course.ts` 是网页运行内容的唯一来源。

公式适用条件、单位、正负号、答案与解析需课程教师复核。原件未提供的需求不凭推测补写。原始申报材料不在公开仓库中，需要核对时由团队通过合适渠道提供。
