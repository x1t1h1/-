# 热知 · 工程热力学学习平台

用于大创项目中期答辩的前端演示工程。页面围绕同一套知识点展开，打通「首页 → 知识图谱 → 仿真实验 → 视频与课件 → 习题 → 个人中心」的学习流程。

## 第一次打开

本项目在浏览器中运行。请保留整个仓库文件夹，不要只复制其中的 HTML 文件。

1. 电脑需要安装 Node.js（包含 npm）。打开终端，执行 `node -v` 和 `npm -v`，都能显示版本即可。
2. 如果当前文件夹中已经存在 `node_modules`，可直接使用下方启动脚本。如果从别的电脑复制了源码、或没有这个文件夹，请先在本项目文件夹中打开终端，执行：

   ```powershell
   npm install
   ```

3. 双击 **`启动演示.cmd`**。脚本会打开服务窗口，并在服务就绪后打开浏览器。
4. 也可以右键 **`启动演示.ps1`**，选择「使用 PowerShell 运行」。如果电脑不允许运行 PowerShell 脚本，请使用上面的 `.cmd` 启动器。
5. 演示期间保持服务窗口打开。结束时回到窗口按 `Ctrl+C` 停止服务。

本地地址：**http://127.0.0.1:5173**。第一次启动编译需要稍等片刻。

启动脚本使用系统 PATH 中的 Node.js 与 npm，请先安装 Node.js 并确认终端能找到它们。脚本不会自动安装依赖，不会结束其他程序。如果 5173 端口已经运行本项目，会复用已启动的页面；如果被其他应用占用，会提示后退出。

也可以在此文件夹的终端中手动启动：

```powershell
npm run dev
```

如果 PowerShell 提示 `npm.ps1` 被执行策略阻止，把命令中的 `npm` 改成 `npm.cmd`，例如 `npm.cmd run dev`。

## AI 助教（交晓智 WebSDK，校内联调）

`index.html` 使用智能体提供者从交晓智“WebSDK → 嵌入设置 → 聊天气泡”复制的官方代码，初始化 `HiagentWebSDK.WebLiteClient`。智能体和知识库继续由交晓智管理；网页只加载平台聊天组件，后端 API 密钥不参与本次接入。`variables` 保持为空，本项目不向 SDK 传入学习记录、错题或仿真参数。

本次使用范围是**本校师生、校园网环境及学校账号访问权限**。学校登录、对话权限和知识库回答均由交晓智提供，本项目没有新建账号系统或后端。校外普通网络、离线 AI 问答、微信小程序端及回答准确率均不属于本次已验证能力。

### 在自己的电脑上运行

1. 连接校园网，用电脑上的 Chrome 或 Edge 打开[已发布的智能体](https://ai.xjtu.edu.cn/product/llm/chat/dbddjmddh9462bgkn8lg)，按平台要求使用学校账号登录，并确认能够完成一次真实问答。
2. 保持同一浏览器，双击 `启动演示.cmd`，打开 `http://127.0.0.1:5173`。已经运行热知时刷新网页即可。
3. 等待交晓智组件加载，点击页面中的官方聊天气泡，输入工程热力学问题，再追问一次，确认真实回答与上下文连续性。气泡界面和位置由官方 SDK 提供，登录状态能否在嵌入窗口中使用仍需在校园网实际确认。
4. 如果提示“AI 助教组件暂未加载”，确认校园网连接，在同一浏览器打开交晓智完成登录后，点击“重新加载助教”。加载提示可以关闭，其他热知功能继续使用。“打开交晓智助教”是独立页面排查入口，不代表已经通过网页内聊天验收。
5. 如果 SDK 已加载，但聊天窗口仍报错或无法登录，请核对交晓智中同一个智能体的 WebSDK 开关、已发布渠道、访问控制及嵌入域名设置。若平台另行配置了嵌入域名限制，应按平台要求允许实际使用的热知地址并发布渠道配置；保持本次要求的学校账号访问范围。

SDK 在热知页面首次加载后异步请求；脚本加载失败、初始化异常或等待超过 12 秒时显示重试提示。脚本加载成功不等于登录或问答成功，后两项必须以真实运行结果为准。官方 SDK 的气泡不受本项目路由切换重新初始化。

## 建议的答辩演示顺序

建议使用电脑浏览器，窗口最大化，浏览器缩放设为 100%。

1. **学习首页**：介绍课程学习空间，进入知识图谱。
2. **知识图谱**：搜索「热力学第一定律」或「卡诺循环」。点击节点查看概念、公式、资源和关联知识；演示章节筛选、拖动、缩放与复位。
3. **视频与课件**：打开关联演示视频，播放一段；查看对应文字课件，标记已学或收藏。
4. **习题练习**：进入对应知识点的习题，选择答案并提交，展示判分与解析。可以故意答错一道，展示错题收集。
5. **个人中心**：查看刚才产生的学习记录、收藏、练习结果和错题。重新做对错题后，错题列表随之更新。

学习记录保存在当前浏览器的 `localStorage` 中。刷新页面仍会保留，但不会自动同步到其他浏览器、其他电脑或云端。更换地址或端口也可能进入独立的浏览器存储空间。个人中心提供记录导出与演示重置；重置会清除该浏览器中的本项目记录。

## 后续怎么添加课程内容

主要编辑 **`src/data/course.ts`**。该文件已给出 TypeScript 数据类型和现有示例。关联依靠稳定的 `id`，而不是页面显示名称；尽量保持已使用的 ID 不变。

| 数据列表 | 作用 | 修改要点 |
| --- | --- | --- |
| `chapters` | 章节目录与颜色 | 每章有唯一 `id`、标题和图例颜色 |
| `nodes` | 知识点、公式与图谱位置 | `chapterId` 对应章节，`x/y` 决定图谱位置，`core` 决定是否突出显示 |
| `relations` | 知识点之间的联系 | `source/target` 填知识点 ID，`type` 填「前置」「包含」或「应用」 |
| `learningPath` | 零基础学习顺序 | 32 个知识点 id 按 ch0–ch12 和章内顺序排列；新增/删除节点时必须同步 |
| `resources` | 视频、文字课件、课程 PDF 及外部网课 | `nodeIds` 可同时关联多个知识点，`chapterId` 用于章节筛选 |
| `questions` | 题干、选项、答案、解析 | `answer` 从 **0** 开始编号：0 对应第一个选项，1 对应第二个选项 |

`learningPath` 必须覆盖全部知识点、不重复，章节分组按 `chapters` 顺序连续，且所有「前置」关系的前置节点要排在后续节点之前。`node scripts/check-content.mjs` 会校验这些约束以及前置关系是否有环。

例如，增加一条关联已有知识点的视频资源，可以参照现有对象填写：

```ts
{
  id: 'video-first-law-new',
  title: '第一定律补充讲解',
  type: 'video',
  nodeIds: ['first-law', 'internal-energy'],
  chapterId: 'ch2',
  duration: '05:20',
  description: '填写视频来源及内容介绍。',
  color: '#317cff',
  theme: 'energy',
  src: '/static/media/my-first-law.mp4',
}
```

将相应视频放到 `src/static/media/my-first-law.mp4`（uni-app 约定：`src/static` 下的文件在构建时复制到发布目录）。浏览器中的路径以 `/static/media/` 开头。建议使用浏览器普遍支持的 H.264 MP4，并核对实际时长。现有视频也可以保留原文件名直接替换；如更换文件名，请同时更新 `src`。封面文件是同目录中的 `*-cover.png`，替换时也应检查资源卡片展示。

文字课件的内容位于资源对象的 `slides` 数组中，每一页包含 `title`、`body`，可选 `formula`。修改这些内容即可更新现有课件。以后接入正式 PPT，可以先整理为这种文字课件数据；课程 PDF 的新标签页阅读入口已经实现；直接预览或下载 PPT 仍未实现，仅把 PPT 放进文件夹不会自动出现预览。

新增题目时请同时补齐解析，确认题目关联的知识点存在，并由课程同学或教师核对公式条件、单位与正负号。内容说明和公式参考见 `src/data/CONTENT_NOTES.md`。

## 仿真模型接入

仿真模型位于 `src/simulations/`。组员提交模型时，需要满足以下要求；完整字段说明与最小示例见 [仿真模型接入指南](docs/SIMULATION_MODEL_GUIDE.md)。

### 接入方式

1. 在 `src/simulations/models/` 新增一个 `.ts` 文件，实现 `src/simulations/types.ts` 中的 `SimulationModel`。
2. 在 `src/simulations/registry.ts` 中 import，并加入 `simulationModels` 数组。
3. 运行类型检查并在浏览器验证。注册后会自动生成实验卡片和独立详情页，**不需要修改页面代码**。

### 必须满足的要求

| 要求 | 说明 |
| --- | --- |
| 纯前端可运行 | 模型必须能在浏览器中运行（TS/JS/WASM）。本项目不引入后端；Python/MATLAB 模型需先导出为 JS/WASM 或独立 HTML。 |
| 契约完整 | 实现 `SimulationModel` 必填字段：`id`、`name`、`description`、`parameters`、`compute`；可选 `shortName`、`category`、`icon`、`accent`、`formula`、`formulaNote`、`chapterIds`。 |
| 唯一 id | `id` 不得与现有模型重复，建议使用 kebab-case，例如 `carnot-cycle`。 |
| 纯函数 compute | 不访问 DOM、不发起网络请求、不读取当前时间或随机数；相同输入必须得到相同输出。 |
| 默认值合法 | 每个参数的 `default` 必须在 `min`/`max` 范围内；默认参数下 `compute` 必须成功（仿真首页会用默认参数生成卡片预览）。 |
| 输入校验 | 非法输入（0、负数、非数字、`T_C ≥ T_H` 等）抛出带中文说明的 `Error`，不能返回 `NaN`/`Infinity`。 |
| 单位统一 | p 用 kPa（绝对压力）、V 用 L、T 用 K；能量内部用 J、展示建议用 kJ；熵变用 J/K。 |
| 符号约定 | 与课程数据一致：`ΔU = Q − W`，`W` 为系统对外做功；放热量按正值展示时需在说明中注明。 |
| 图表规范 | 每张图必须有唯一的 `id`、`title`、`xLabel`、`yLabel`（含单位）；单图建议 40–120 个采样点；返回多张图时详情页会自动显示切换标签。 |
| 指标与状态 | `metrics` 给出关键结果与单位；`states` 给出状态点（没有状态点时返回空数组）；所有数值必须是有限数字。 |
| 计算轻量 | 首页会为每张卡片计算一次预览，`compute` 不应做重计算或异步操作。 |
| 内容准确 | 公式、适用条件、单位、正负号需课程同学或教师复核；`chapterIds` 只能引用 `src/data/course.ts` 中已有章节。 |
| 安全 | 不写入密钥、服务器地址或个人敏感信息；不在模型内发起外部请求。 |
| 不破坏现有结构 | 只新增模型文件并在注册表加一行；不修改现有页面、路由、配置或依赖。确需新增依赖时先与团队确认。 |

### 提交前检查

```powershell
npm run typecheck
node scripts/check-content.mjs   # 修改了课程数据时
npm run build
```

浏览器中至少确认：

- 仿真首页出现新卡片，默认参数下的预览图正常；
- 点击卡片进入 `pages/simulation/detail?model=<id>`；
- 调节参数后图表、指标卡、状态表同步更新；
- 非法输入显示中文错误，恢复默认值可恢复；
- 1440px 桌面宽度与手机宽度下无横向溢出；
- 控制台无报错。

现有示例模型包括 `src/simulations/models/carnotCycle.ts`（卡诺循环，p–V 与 T–s 两张图）和 `src/simulations/models/idealGasProcesses.ts`（定温、定压、定容、绝热四个过程），可作为实现参考。

## PDF 与网课维护

PDF 保存在 `src/static/courseware/`，资源类型为 `pdf`，`src` 使用 `/static/courseware/文件名.pdf`。资源页通过新标签页打开 PDF，手机可能下载或调用外部阅读器。PDF 原件不修改，来源标注为西交工热mooc；如有侵权请联系删除，内容需课程教师复核。

PDF 与网课卡片按 `chapterId` 自动使用 `src/static/media/covers/chXX-cover.svg` 章节封面。封面由 `node scripts/media/generate_covers.mjs` 生成；替换封面时保持文件命名，或在资源对象上添加可选 `cover` 字段单独指定。封面 SVG 不含中文标题，章节名与资源类型由页面叠加显示。

网课使用 `external` 类型及 `url`；已核对分集链接带真实 `p` 序号。`nodeIds` 可为空，表示仅关联章节。运行数据唯一来源仍为 `src/data/course.ts`；`docs/bilibili-directory.json` 是检查用目录快照，不作为前端数据源。修改分集时必须同时核对快照与关联清单，不能猜测章节或分集序号。

## 检查、构建与交接

在项目文件夹中执行：

```powershell
# 检查 TypeScript 和 Vue 类型
npm run typecheck

# 检查知识点、题目、资源之间的引用和本地文件
node scripts/check-content.mjs

# 生成可部署的 H5 静态文件
npm run build
```

生产文件通常生成在 `dist/build/h5`，应通过 HTTP 静态服务器访问；不建议直接双击其中的 `index.html`。当前答辩使用启动脚本即可，不需要先构建。
